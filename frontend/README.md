# UGC Platform - Frontend

React + TypeScript + Vite frontend for the UGC Platform.

## Setup

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Structure

```
src/
├── pages/         # Page components
├── components/    # Reusable components
├── slices/        # Redux slices
├── hooks/         # Custom hooks
├── services/      # API services
├── types/         # TypeScript types
└── App.tsx        # Main app component
```
